# Disclosure boundary

The following remain private:

- Original project implementation, architecture, internal decisions, memory/control systems, and roadmaps.
- Personal contact details, private conversations, home paths, location data, device identifiers, and network identifiers.
- Credentials, signing material, authentication data, private endpoints, and financial information.
- Source repository names, internal paths and revisions, private CI links, audit inventories, and implementation hashes.
- Raw prompts, responses, benchmark tasks, hidden tests, score ledgers, datasets, logs, archives, and screenshots.
- Model weights, adapters, vendor binaries, APKs, and material without confirmed redistribution rights.
- Original Git histories, staging repositories, private artifacts, and unreviewed third-party source.

Only new synthetic fixtures and reviewed high-level summaries are included. They are not a training corpus or a generalization benchmark. Failures remain recorded in the private research evidence.

The public professional name and GitHub alias are intentional portfolio attribution. They are distinct from private contact information. Git author and committer addresses must use the exact GitHub noreply domain.
