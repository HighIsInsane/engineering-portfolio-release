# Provenance and source rights

The case studies summarize an authorized review of private research work. All runnable examples, tests, tools, and fixtures were newly authored with AI assistance for this portfolio. They are synthetic concept demonstrations; no private implementation, task packet, third-party library source, or original Git history is distributed here.

The Python examples use the standard library and installed Git executable. CI references its external checkout action by immutable revision; that action is not vendored or relicensed.

The MIT license applies only to the newly authored portfolio material to the extent its owner may license it. It does not license the underlying private projects, model outputs, model weights, vendor SDKs, or upstream work. Repository access and commit attribution alone do not establish exclusive copyright.

Public claim identifiers refer to the summaries in this repository. Private source repository names, revisions, source paths, CI identifiers, and implementation hashes are withheld. The original audit records remain private, including unsuccessful experiments and limitations. This privacy reduction does not modify those records or convert their failures into successes.

The release candidate starts with a new Git root and an explicit GitHub noreply identity. No branches, tags, run records, or Git objects are imported from earlier staging repositories. An earlier staging repository must remain private; a local history rewrite cannot establish deletion of objects or caches hosted elsewhere.

Owner approval is required before any public release. Hashes link the disclosed files to their validation results; they do not independently establish historical authenticity or legal ownership.
